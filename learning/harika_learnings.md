Personal Learning Log: ELIZA Reconstruction

  Project Scope: Rebuilding the historical ELIZA chatbot simultaneously in three languages: Go,
  Elixir, and Rust.

   Technical Insights: How ELIZA Works
   * Rule-Based vs. ML: Unlike modern AI (ChatGPT, Claude), ELIZA uses simple, scripted responses
     rather than machine learning. It doesn't actually comprehend English.
   * Keyword Routing: It scans user prompts and selects a response path based entirely on the
     highest-priority keyword it recognizes.
   * Pronoun Reflection: It automatically converts pronouns (e.g., swapping "I" to "you") to reflect
     statements back at the user naturally.
   * The "DOCTOR" Persona: It mimics a Rogerian psychotherapist by frequently answering statements
     with questions, creating a clever illusion of understanding.

   Software Engineering Practices
   * Version Control: Learned fundamental Git commands, recognizing its essential role in safely
     tracking changes and managing a codebase.
   * The Power of Documentation: Discovered that clear documentation is the most important part of a
     project. Having a solid plan and well-written guides beforehand made the actual implementation
     phase significantly easier and more efficient.
