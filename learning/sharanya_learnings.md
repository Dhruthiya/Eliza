## About the Eliza Project
- Eliza is a recreation of the classic 1966 chatbot by Joseph Weizenbaum
- It simulates a therapist by pattern-matching user input against keywords and responding with scripted replies
- Mainly worked on the **Elixir** implementation of Eliza
- Core data (keywords, synonyms, responses) is stored in JSON files under `/data`
